# Changelog

Todas as mudanças relevantes deste projeto são registradas aqui.
O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e o projeto usa [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] — 2026-10-31

### Adicionado
- Visualizador de código-fonte com destaque de sintaxe para HTML, CSS e JavaScript.
- Temas Escuro (Dark+), Claro (Light+) e Auto, inspirados no Visual Studio Code.
- Fonte Source Code Pro embutida.
- Interceptação automática de `view-source:` (pode ser desligada).
- Ícone na barra, atalho `Alt+Shift+U` e itens no menu de contexto.
- Números de linha clicáveis com link `#L<n>`.
- Links navegáveis em `href` e `src`.
- Controles de tamanho de fonte, quebra de linha, copiar e abrir a página original.
- Preferências sincronizadas via `chrome.storage.sync`.
